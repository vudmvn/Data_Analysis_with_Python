\subsection*{Technical Rationales for Multiple-Choice Items}
\begin{itemize}[leftmargin=*, itemsep=3.5pt]
  \item \textbf{Q1 (Key B):} \texttt{np.arange(start=2, stop=11, step=2)} generates sequence values starting at 2 up to, but excluding, 11 with increment 2: \texttt{[2, 4, 6, 8, 10]}.
  \item \textbf{Q2 (Key A):} The nested list \texttt{[[10, 20, 30], [40, 50, 60]]} has 2 rows and 3 columns. Thus, its shape is \texttt{(2, 3)} and its number of dimensions (\texttt{ndim}) is \texttt{2}.
  \item \textbf{Q3 (Key C):} In standard NumPy 2D array indexing \texttt{m[row, col]}, row index 1 and column index 2 accesses the element with value \texttt{6}.
  \item \textbf{Q4 (Key B):} In NumPy 2D operations, \texttt{axis=0} specifies aggregation along rows (down each column). For shape \texttt{(4, 5)}, computing the mean along \texttt{axis=0} produces a 1D array of 5 column means.
  \item \textbf{Q5 (Key D):} A Pandas \texttt{Series} is a 1-dimensional labeled array supporting homogeneous types, while a \texttt{DataFrame} is a 2-dimensional labeled tabular data structure with columns potentially of different types.
  \item \textbf{Q6 (Key A):} \texttt{df.iloc} is strictly integer position-based (0 to length-1). \texttt{df.iloc[0]} retrieves the first row, whereas \texttt{df.loc} indexes by label names.
  \item \textbf{Q7 (Key C):} \texttt{df.isna()} (or \texttt{df.isnull()}) produces a boolean DataFrame of the same shape, and calling \texttt{.sum()} sums the boolean flags (\texttt{True}=1) along columns to report the total missing count per column.
  \item \textbf{Q8 (Key A):} Pandas boolean filtering requires bitwise operators (\texttt{\&} for AND, \texttt{|} for OR) and explicit parentheses around each condition: \texttt{df[(df['City'] == 'Hanoi') \& (df['Age'] >= 20)]}. The Python logical operator \texttt{and} causes an ambiguity error on Series.
  \item \textbf{Q9 (Key B):} A line chart is standard for time-series data because the connecting lines clearly communicate continuous trajectories, temporal trends, and cyclical patterns across chronological order.
  \item \textbf{Q10 (Key D):} A box plot (\texttt{sns.boxplot}) provides a visual summary of the 5-number summary (min, $Q_1$, median, $Q_3$, max) and plots individual markers for outliers falling outside $1.5 \times IQR$ fences.
  \item \textbf{Q11 (Key C):} The \texttt{hue} parameter maps categorical levels to distinct color palettes, enabling visual grouping and segmentation without creating separate subplots.
  \item \textbf{Q12 (Key A):} \texttt{plt.tight\_layout()} automatically adjusts subplot parameters and margins so that titles, tick marks, and axis labels fit within the figure without overlapping.
\end{itemize}

\subsection*{Question 1: Retail Sales Analysis with NumPy \& Pandas (2.0 pts)}

\subsubsection*{Standard Model Solution}
\begin{lstlisting}
# a) Vectorized Revenue calculation (0.4 pts):
df['Revenue'] = df['Price'] * df['Quantity'] * (1 - df['Discount'])

# b) Conditional Priority classification with np.where (0.4 pts):
df['Priority'] = np.where((df['Revenue'] >= 1000) | (df['Quantity'] >= 5), 'High', 'Standard')

# c) Filter Tech orders with Quantity >= 2 (0.4 pts):
tech_orders = df[(df['Category'] == 'Tech') & (df['Quantity'] >= 2)]

# d) Groupby Category and compute sum and mean (0.4 pts):
summary = df.groupby('Category')['Revenue'].agg(['sum', 'mean'])
# Alternative acceptable syntax:
# summary = df.groupby('Category').agg({'Revenue': ['sum', 'mean']})

# e) Sort summary table by total revenue descending (0.4 pts):
final_sorted = summary.sort_values(by='sum', ascending=False)
# If multi-level column indexing is produced: summary.sort_values(by=('Revenue', 'sum'), ascending=False)
\end{lstlisting}
