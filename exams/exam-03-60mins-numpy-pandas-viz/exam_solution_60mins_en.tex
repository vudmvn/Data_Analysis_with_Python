\subsection*{Technical Rationales for Multiple-Choice Items}
\begin{itemize}[leftmargin=*, itemsep=3.5pt]
  \item \textbf{Q1 (Key A):} \texttt{np.linspace(0, 10, 5)} generates 5 evenly spaced float values: \texttt{[0.0, 2.5, 5.0, 7.5, 10.0]}. \texttt{np.arange(1, 6)} generates \texttt{[1, 2, 3, 4, 5]}. Multiplying by 2 yields \texttt{[2, 4, 6, 8, 10]}. Element-wise addition gives \texttt{[2.0, 6.5, 11.0, 15.5, 20.0]}.
  \item \textbf{Q2 (Key B):} Slicing creates an ndarray \textit{view}, sharing the data buffer with matrix \texttt{m}. The slice \texttt{m[::-1, 1]} extracts column index 1 in reverse order: element at row 2 (\texttt{80}), row 1 (\texttt{50}), and row 0 (\texttt{20}). Modifying \texttt{v[0] = 999} mutates \texttt{m[2, 1]} to 999. \texttt{v[2]} refers to \texttt{m[0, 1]}, which is 20. Output: \texttt{999 20}.
  \item \textbf{Q3 (Key A):} Arrays align from the trailing dimension: $A: (4, 1, 6)$, $B: (3, 1)$. Adding leading singleton: $B: (1, 3, 1)$. Comparing dimensions: axis 2: $(6, 1) \rightarrow 6$; axis 1: $(1, 3) \rightarrow 3$; axis 0: $(4, 1) \rightarrow 4$. Result shape of $A \times B$ is $(4, 3, 6)$. Adding \texttt{np.zeros(6)} preserves shape $(4, 3, 6)$.
  \item \textbf{Q4 (Key A):} Boolean condition evaluates whether elements are even and strictly greater than 10.
  Row 0 of \texttt{x}: 12 is even and $> 10 \rightarrow 12 \times 2 = 24$; 25 is odd $\rightarrow 0$; 8 is not $> 10 \rightarrow 0$.
  Row 1 of \texttt{x}: 30 is even and $> 10 \rightarrow 60$; 15 is odd $\rightarrow 0$; 22 is even and $> 10 \rightarrow 44$.
  Sum along \texttt{axis=0} (columns): $[24+60, 0+0, 0+44] = \texttt{[84, 0, 44]}$.
  \item \textbf{Q5 (Key B):} Series addition aligns on index labels. \texttt{fill\_value=0} replaces missing values before addition. \texttt{'Da Nang'} is present only in $S_1$ (30.0 + 0 = 30.0); \texttt{'Can Tho'} is present only in $S_2$ (0 + 15.0 = 15.0).
  \item \textbf{Q6 (Key A):} Label-based slicing (\texttt{.loc}) is inclusive of both start and stop boundaries (\texttt{'Q2'}, \texttt{'Q3'}, \texttt{'Q4'} $\rightarrow 3$ rows). Integer positional slicing (\texttt{.iloc}) uses standard Python half-open semantics $[1, 3)$ ($\rightarrow 2$ rows: indices 1 and 2).
  \item \textbf{Q7 (Key B):} Filtering the grouped aggregation table for tuple key \texttt{('North', 'Food')}: rows with \texttt{Region == 'North'} and \texttt{Category == 'Food'} are order 0 (Sales 100) and order 4 (Sales 200). Sum = $100 + 200 = 300$.
  \item \textbf{Q8 (Key B):} A Left Merge preserves all records of the left DataFrame $A$ ($N = 500$ rows). The 30 rows that have no matching key in table $B$ retain their left attributes and receive \texttt{NaN} for columns originating from $B$.
  \item \textbf{Q9 (Key A):} In Matplotlib's 2D subplots array, indexing uses 0-based matrix notation \texttt{[row, column]}. First row is index 0; second column is index 1. Method call: \texttt{axes[0, 1].set\_title(...)}.
  \item \textbf{Q10 (Key B):} A Boxplot simultaneously displays the median (50th percentile), interquartile range ($IQR = Q_3 - Q_1$), and flags extreme outliers beyond $1.5 \times IQR$ whisker fences as individual points.
  \item \textbf{Q11 (Key A):} In Seaborn relational plotting, \texttt{hue} maps categorical groupings to distinct colors, while \texttt{style} maps categories to distinct point marker glyphs (circles, crosses, diamonds).
  \item \textbf{Q12 (Key B):} In \texttt{sns.heatmap}, \texttt{annot=True} renders correlation numbers inside cells; \texttt{plt.tight\_layout()} adjusts subplot margins to prevent clipping.
\end{itemize}
