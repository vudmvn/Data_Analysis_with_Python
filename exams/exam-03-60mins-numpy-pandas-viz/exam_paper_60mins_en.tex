  \item \texttt{sns.barplot()}
  \item \texttt{sns.boxplot()}
  \item \texttt{sns.countplot()}
  \item \texttt{sns.lineplot()}
\end{enumerate}
\end{multicols}

\item Consider the following Seaborn relational plotting statement:
\begin{lstlisting}
import seaborn as sns
sns.scatterplot(data=df, x='Marketing_Spend', y='Revenue', hue='Channel', style='Tier')
\end{lstlisting}
What role do the parameters \texttt{hue='Channel'} and \texttt{style='Tier'} play in the resulting visualization?
\begin{enumerate}[label=\Alph*.]
  \item \texttt{hue} maps channel categories to distinct point colors; \texttt{style} maps tier categories to distinct marker shapes (glyphs).
  \item \texttt{hue} adjusts point opacity; \texttt{style} sets the background CSS layout.
  \item \texttt{hue} partitions data into separate subplots; \texttt{style} specifies the font style.
  \item Both parameters are synonymous and map data to line width.
\end{enumerate}

\item Given the Pearson correlation matrix computation and visualization:
\begin{lstlisting}
corr_matrix = df[['Age', 'Income', 'Spending_Score', 'Tenure']].corr()
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
plt.tight_layout()
\end{lstlisting}
What is the primary function of \texttt{annot=True} and \texttt{plt.tight\_layout()} respectively?
\begin{enumerate}[label=\Alph*.]
  \item \texttt{annot=True} adds interactive tooltips; \texttt{plt.tight\_layout()} compresses the image to a low-resolution thumbnail.
  \item \texttt{annot=True} writes numeric correlation coefficients inside each cell; \texttt{plt.tight\_layout()} adjusts subplot margins to prevent label clipping.
  \item \texttt{annot=True} filters out correlations near zero; \texttt{plt.tight\_layout()} converts the plot to black and white.
  \item \texttt{annot=True} prints p-values; \texttt{plt.tight\_layout()} locks axes aspect ratios to 1:1.
\end{enumerate}

\end{enumerate}
