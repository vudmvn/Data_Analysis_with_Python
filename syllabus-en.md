## 3. Course Description

The course provides a systematic introduction to data science and business data analytics using Python. Students will become familiar with standard tools and environments including Anaconda, Python, IPython, JupyterLab, and Jupyter Notebook.

The course content covers core skills in the data analysis workflow: data manipulation, statistical computing, linear algebra, visualization, data collection and storage, data cleaning, feature transformation, and predictive model building. Through lab exercises and projects, students utilize Python libraries such as NumPy, SciPy, Pandas, Matplotlib, Seaborn, Bokeh, and scikit-learn to solve problems in business, economics, and related fields.

The course also introduces foundational concepts in advanced data analytics, including data segmentation, clustering, linear and non-linear regression, binary classification, multiclass classification, and model evaluation.

## 4. Course Objectives

Upon successful completion of the course, students will be able to:

1. Identify the role and scope of popular data science and data analysis libraries.
2. Utilize NumPy and SciPy to perform statistical calculations, linear algebra operations, and matrix manipulations.
3. Visualize data using Matplotlib, Seaborn, and Bokeh.
4. Read, write, fetch, and store data across multiple file formats and database systems using NumPy, Pandas, SQLite, and PyMongo.
5. Clean, manipulate, transform, and reshape data for analytical tasks.
6. Apply foundational techniques in data segmentation, clustering, regression, and classification.
7. Develop self-study capabilities, independent work habits, teamwork skills, and personal accountability for assigned tasks.

## 5. Course Learning Outcomes (CLOs)

### 5.1. Tools and Libraries

- Describe the role of popular libraries in data science.
- Install and configure necessary tools and environment libraries for data analysis tasks.

### 5.2. Statistical Computing and Linear Algebra

- Use NumPy and SciPy to perform statistical calculations.
- Perform linear algebra, matrix, and vector operations.

### 5.3. Data Visualization

- Understand chart purposes and selection criteria for different data types.
- Construct basic visualizations using Matplotlib.
- Construct statistical visualizations using Seaborn.
- Construct interactive visualizations using Bokeh.

### 5.4. Data Access and Storage

- Read and write CSV data using NumPy and Pandas.
- Work with Excel, JSON, HTML, and PDF file formats.
- Connect, read, and store data in relational and NoSQL databases using SQLite and PyMongo.

### 5.5. Data Cleaning and Preprocessing

- Filter data and reduce noise.
- Handle missing values and outliers.
- Perform encoding, normalization, feature transformation, and dataset splitting.

### 5.6. Analytics and Model Building

- Perform basic data segmentation and clustering tasks.
- Build and evaluate regression models.
- Build and evaluate classification models.

### 5.7. Autonomy and Responsibility

- Develop capacity for self-learning and independent work.
- Demonstrate individual accountability and team responsibility.

## 6. Course Outline

| Week | Topic | Main Content |
|---:|---|---|
| 1 | **Course Introduction** | Syllabus overview; course requirements; Anaconda, Python, IPython, JupyterLab, and Jupyter Notebook environment. |
| 2–3 | **Statistical Computing & Linear Algebra** | Introduction to NumPy & Pandas; statistical functions; linear algebra & matrix operations. |
| 4 | **Data Exploration & Visualization** | Visualization with Matplotlib; statistical plots with Seaborn; interactive charts with Bokeh. |
| 5 | **Data Access & Storage Systems** | File I/O across formats; working with relational databases (MySQL) and NoSQL (MongoDB). |
| 6 | **Data Cleaning & Preprocessing** | Noise filtering; missing value imputation; outlier handling; encoding, scaling, transformation & feature splitting. |
| 7 | **Midterm Examination** | Review and evaluation of topics covered from Week 1 to Week 6. |
| 8–9 | **Data Segmentation & Clustering** | Segmentation approaches; segmentation criteria; clustering algorithms; evaluation & selection. |
| 10–11 | **Data Forecasting & Linear Regression** | Linear models; feature engineering for regression; model interpretation; evaluation metrics. |
| 12 | **Non-linear Regression** | Logistic regression; building data processing pipelines and workflow modeling. |
| 13 | **Binary Classification** | Support Vector Machines (SVM), Decision Trees, Random Forests; data preprocessing; evaluation metrics. |
| 14 | **Multiclass Classification** | Multiclass models; classification strategies; performance metrics; handling imbalanced datasets. |
| 15 | **Summary & Review** | Knowledge synthesis, Q&A session, and final assessment preparation. |

## 7. Teaching and Learning Methods

The course combines:

- Theoretical lectures and live coding demonstrations.
