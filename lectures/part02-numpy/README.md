# Tuần 02: Thư viện tính toán số NumPy (Numerical Computing with NumPy)

## 🎯 Mục tiêu bài học (Learning Objectives)
- Nắm vững cấu trúc dữ liệu mảng n-chiều (`ndarray`) và thuộc tính cốt lõi trong NumPy.
- Áp dụng các kỹ thuật định hình (reshaping), cắt lát (slicing), chỉ số hóa (indexing) và truy vấn dữ liệu (boolean filtering).
- Hiểu và vận dụng thành thạo tính toán vector hóa (vectorization) và cơ chế mở rộng mảng (broadcasting).
- Thực hiện các phép toán đại số tuyến tính, tính toán thống kê và xử lý dữ liệu thiếu (`NaN`).
- Tích hợp mảng NumPy với các thư viện trong hệ sinh thái Data Science (Pandas, SciPy, Scikit-learn).
