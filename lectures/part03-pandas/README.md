# Tuần 03: Thư viện thao tác dữ liệu Pandas (Data Manipulation with Pandas)

## 🎯 Mục tiêu bài học (Learning Objectives)
- Nắm vững cấu trúc dữ liệu cốt lõi trong Pandas: `Series` (1 chiều) và `DataFrame` (2 chiều).
- Thành thạo các phương pháp chỉ số hóa, cắt lát và truy vấn dữ liệu (`.loc`, `.iloc`, boolean indexing).
- Đọc và ghi dữ liệu từ nhiều định dạng tập tin phổ biến (CSV, Excel, JSON, SQL, Parquet).
- Làm sạch và tiền xử lý dữ liệu: xử lý giá trị thiếu (`NaN`), trùng lặp, chuyển đổi kiểu dữ liệu và chuẩn hóa chuỗi ký tự.
- Thực hiện biến đổi dữ liệu nâng cao: Gom nhóm (`groupby`), tổng hợp (`agg`), xoay bảng (`pivot_table`), gộp dữ liệu (`merge`, `concat`).
- Ứng dụng Pandas trong phân tích dữ liệu chuỗi thời gian (Time Series), phân tích kinh doanh và kinh tế.
