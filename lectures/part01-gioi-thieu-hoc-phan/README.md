# Tuần 01: Giới thiệu học phần (Course Introduction & Overview)

## 🎯 Mục tiêu bài học (Learning Objectives)
- Hiểu rõ khái niệm và vai trò của **Phân tích dữ liệu** (Data Analysis) trong khoa học và kinh doanh.
- Nắm vững **6 bước trong quy trình phân tích dữ liệu**: Xác định bài toán, Thu thập dữ liệu, Làm sạch dữ liệu, Phân tích khám phá (EDA), Mô hình hóa và Trực quan hóa & Báo cáo.
- Làm quen với các phương pháp **Phân tích thống kê** mô tả và phân tích tương quan cơ bản trong Python.
- Thiết lập môi trường làm việc: Python, Anaconda, JupyterLab và các thư viện cốt lõi (`numpy`, `pandas`, `matplotlib`, `seaborn`).
